# Telegram Messages Sender

[English](README.md) · **Русский**

Локальное приложение для macOS, которое регулярно публикует сообщения через отдельную сессию вашего личного аккаунта Telegram. Очередью отправки управляет настольное приложение. Утилита `tmsctl` подключается к нему с проверкой подлинности по локальному loopback-соединению и управляет той же очередью.

## Сборка и запуск

Понадобятся Mac с Apple Silicon, Go 1.26.3 (версия из `go.mod`) и Xcode Command Line Tools. При необходимости установите их командой `xcode-select --install`. Минимальная целевая версия системы — macOS 15.0. Версии, использованные при запуске и тестировании, указаны в разделе [«Проверка на macOS»](#проверка-на-macos).

```sh
go mod download
sh ./scripts/package-macos.sh
open dist/telegram-messages-sender.app
./dist/tmsctl status
```

Скрипт собирает оба исполняемых файла для arm64 с CGO, проверяет минимальную версию macOS в Mach-O и параметры `Info.plist`, затем подписывает сборку локальной ad-hoc-подписью. Пакет приложения и отдельный CLI появятся в `dist/`. Версия пакета — `1.0.0`.

## Настройка Telegram

1. Получите API ID и API hash в разделе **API development tools** на my.telegram.org. [Инструкция Telegram по получению API ID](https://core.telegram.org/api/obtaining_api_id)
2. Откройте **API credentials**, введите полученные значения и нажмите **Save to Keychain**.
3. Нажмите **Sign in**, отсканируйте QR-код через раздел привязки устройств в Telegram и введите пароль двухэтапной аутентификации, если Telegram его запросит. В окне приложения отобразятся подтверждённый аккаунт и статус подключения.
4. Нажмите **New publication**. Задайте постоянный идентификатор, например `announcements`, и интервал, например `20m`. Добавьте варианты сообщения и чаты назначения, сохраните публикацию и нажмите **Start**.

Авторизованная сессия даёт доступ к личному аккаунту Telegram. Храните API hash и записи связки ключей в секрете. Если вы потеряли контроль над сессией, завершите её в разделе Telegram **Устройства** и войдите заново. Настройки публикаций и история отправок хранятся в SQLite в каталоге `~/Library/Application Support/telegram-messages-sender/`. Данные API и сессии хранятся в связке ключей macOS.

Чтобы сменить аккаунт, нажмите **Sign out** и подтвердите действие кнопкой **Sign out and delete data**. Приложение завершит свою сессию Telegram и удалит локальные публикации, историю отправок и привязку аккаунта. Данные API сохранятся для следующего входа.

Если Telegram не подтвердит выход, нажмите **Delete local data**, чтобы удалить сессию и данные аккаунта на Mac. Если сессия приложения всё ещё отображается в разделе Telegram **Устройства**, завершите её там.

## Публикации и управление

- Введите текст вручную или выберите сообщение из «Избранного» с текстом, одной фотографией или одним видео. Перед каждой новой отправкой приложение заново получает сообщение из источника. При пересылке из «Избранного» приложение запрашивает скрытие сведений об исходном отправителе и сохранение подписи к медиа. Отображение сведений об отправителе, подписей и форматирования в Telegram ещё предстоит проверить.
- Выбирайте обычные группы или супергруппы без тем, где вы состоите и можете отправлять сообщения от своего профиля. Каналы, темы форума, отправка от имени анонимного администратора, альбомы и отдельные вложения в виде файлов не поддерживаются.
- По умолчанию подключённый аккаунт должен быть администратором или владельцем группы. Включите **Allow sending without administrator rights**, чтобы публиковать от имени обычного участника там, где Telegram это разрешает. Настройка действует для всех публикаций.
- Повторы планируются для каждой пары «публикация — чат» с учётом подтверждённой доставки. Новый цикл начинается с первого чата. Для остальных чатов рассчитываются отдельные задержки от начала того же цикла. Пропущенные за время простоя отправки объединяются. Когда вы закрываете последнее окно, приложение прекращает запуск новых отправок и ограниченное время ждёт завершения текущей попытки.

```sh
./dist/tmsctl status
./dist/tmsctl start announcements
./dist/tmsctl stop announcements
./dist/tmsctl change-interval announcements 30m
./dist/tmsctl re-enable-chat supergroup:123456789
```

Идентификаторы публикаций и чатов берите из вывода `status`. После успешного изменения команда возвращает сохранённую ревизию в JSON. Если настольное приложение закрыто, CLI возвращает ошибку.

| Статус | Что означает |
| --- | --- |
| Утрачены права | Чат отключён во всех публикациях. Восстановите нужные права и явно включите чат, чтобы запустить повторную проверку. |
| Не удалось проверить права или отправка ограничена | Приложение пропускает отправку, пока не может проверить разрешение на публикацию или отправку от личного профиля. |
| Источник недоступен или варианты исчерпаны | При временной недоступности источника приложение повторяет попытку. Если сообщение удалено и это подтверждено, соответствующий вариант становится недоступным. Когда варианты заканчиваются, публикация приостанавливается. |
| Сессия истекла, аккаунт не совпадает или нет доступа к связке ключей | Отправка заблокирована. Проверьте доступ к связке ключей или войдите в аккаунт, к которому привязаны настройки публикаций. |
| Telegram требует подождать | Приложение откладывает работу для указанного чата или всего аккаунта до истечения времени ожидания. |
| Доставка не подтверждена | Telegram мог принять сообщение. Попытка остаётся видимой, и приложение использует данные, полученные позднее, чтобы подтвердить доставку. Следующая плановая отправка считается новой попыткой. |

## Проверка на macOS

```sh
go test ./...
go vet ./...
go test -race ./internal/control ./internal/dispatch
sh ./scripts/package-macos.sh
xcrun lipo -archs dist/telegram-messages-sender.app/Contents/MacOS/telegram-messages-sender
xcrun vtool -show-build dist/telegram-messages-sender.app/Contents/MacOS/telegram-messages-sender
xcrun vtool -show-build dist/tmsctl
plutil -p dist/telegram-messages-sender.app/Contents/Info.plist
```

Замеры выполнены на Mac с Apple M5 (`Mac17,2`, 16 ГиБ оперативной памяти) под macOS 26.5.1 (25F80). Пакет собран с Go 1.26.3, Fyne 2.8.1 и Command Line Tools с SDK macOS 14.0. Оба исполняемых файла имеют архитектуру `arm64` и значение `minos 15.0` в Mach-O. В пакете приложения указано `LSMinimumSystemVersion = 15.0`.

| Показатель | Результат на Mac разработчика |
| --- | --- |
| Размер на диске (`du -sk`) | Пакет приложения: 62 336 КиБ (60,9 МиБ), CLI: 5 560 КиБ (5,4 МиБ). |
| CPU и память в простое | Медиана: 0,9% CPU (0,7–1,0%) и 136 992 КиБ RSS (133,8 МиБ). Пять замеров командой `ps -o %cpu=,rss=` с интервалом в две секунды, начиная через десять секунд после запуска. Одно видимое окно, пустая база данных, без авторизации в Telegram. |
| Число процессов | Один процесс приложения, без дочерних процессов в простое. |
| Первый запуск | 1,28 с до успешного ответа CLI и 1,72 с до обнаружения видимого окна. Отсчёт от `open -n`, приложение запущено с чистыми данными. |
| Повторные запуски | Два следующих запуска заняли 0,08–0,09 с до ответа CLI и 0,50–0,57 с до появления окна. |

При принудительном запуске второго экземпляра первый сохранил управление очередью. CLI получил его статус и вернул его ошибку при запросе неизвестной публикации. Штатное завершение удалило точку подключения. После принудительной остановки CLI отклонил оставшуюся точку подключения, а при следующем запуске приложение заменило её. На отдельно подписанной тестовой копии проверили закрытие последнего окна через штатное действие AppKit. После закрытия CLI сообщил, что приложение остановлено. В среде разработки терминалу не хватало разрешения Accessibility, чтобы нажать кнопку закрытия в исходном пакете приложения.

В изолированной тестовой копии с ad-hoc-подписью проверили работу того же адаптера связки ключей с временными данными API и сессии. Подтвердили создание, обновление, повторное использование после перезапуска и отказ в доступе при ограничениях ACL. Тестовые записи удалены.

- **Запуск на macOS 15** предстоит проверить на Mac с Apple Silicon и этой версией системы.
- **Проверка в Telegram** предстоит для входа и повторного использования сессии, отправки ручного текста, текста, фото и видео из «Избранного», отображения отправителя, отметки о пересылке, подписей и форматирования со стороны получателя, а также восстановления по истории обновлений.
